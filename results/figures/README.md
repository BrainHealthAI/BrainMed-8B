# Historical figures — not the current research summary

The PNG/PDF files in this directory were produced before the 20 October 2026
documentation review. They are retained as historical artifacts.

Some figures mix published scores with locally measured scores or rank models
without a matched evaluation protocol. They must not be used to support a claim
of superiority, clinical validity or a stable gain over the measured base.

Use [REPORT.md](../REPORT.md) and the [main README](../../README.md) for current
interpretation. Regenerate any publication figure from a frozen analysis that
separates sweep/final, includes the measured base, identifies all task weights
and uses paired uncertainty when per-case data become available.
